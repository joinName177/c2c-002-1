# c2c-002 · 情绪植物园

Vue 3 + TypeScript + Vite 纯前端情绪记录与虚拟植物花园。每日记录情绪会种下一株对应植物，连续记录让植物从种子、发芽、开花到结果；断签后保留枯萎标本，并提供生长时间轴和情绪生态年报。数据保存在浏览器 `localStorage`。

支持自建记录目标（每天记录一次 / 某类情绪连续记录 N 天），花园首页直接展示每个目标的进度；目标达成当天弹出成就并收入成就馆；断签的挑战会保留为「已中断」记录，可重新开始新一轮，新周期只累计本轮天数。目标进度、植物连续天数与成就记录共用同一套日期与连续口径。

## 分层

- 核心层 `src/core`：情绪记录、连续天数、植物生长阶段、枯萎判断、生态年报、目标周期结算与成就
- 端口层 `src/ports`：花园快照仓储接口
- 适配器层 `src/adapters`：浏览器本地存储实现
- 界面层 `src/ui`：Vue 页面与原生 CSS 视图

## 命令

```bash
npm install
npm run dev
npm run build
docker compose up --build
```
