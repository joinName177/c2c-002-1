# c2c-002 · 情绪植物园

Vue 3 + TypeScript + Vite 纯前端情绪记录与虚拟植物花园。每日记录情绪会种下一株对应植物，连续记录让植物从种子、发芽、开花到结果；断签后保留枯萎标本，并提供生长时间轴和情绪生态年报。数据保存在浏览器 `localStorage`。

还可以自己设定目标（每天记录一次，或连续记录某一类情绪 N 天），花园首页直接看到每个目标的进度；达成当天弹出一枚成就并收进「成就」页可随时回看。目标做到一半断签时，该轮次保留为「已中断」（不静默归零），可重新开始一轮独立计数的新周期。

## 分层

- 核心层 `src/core`：情绪记录、连续天数、植物生长阶段、枯萎判断、目标周期结算、成就、生态年报
- 端口层 `src/ports`：花园快照仓储接口
- 适配器层 `src/adapters`：浏览器本地存储实现（含旧存档字段兼容）
- 界面层 `src/ui`：Vue 页面与原生 CSS 视图

## 日期与连续口径

目标进度、连续天数、成就日期统一走 `src/core/date.ts` 的本地日期键（`YYYY-MM-DD`）与连续天数工具，植物与目标共用 `syncPlants` / `syncGoals` 同一套结算：今天尚未记录不算断（一天宽限），整天没有命中记录才冻结轮次；`syncGoals` 幂等，重复结算不会重复发放成就。
